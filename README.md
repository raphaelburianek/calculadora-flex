# ⛽ Calculadora Flex & Economia

> Um mini projeto front-end desenvolvido com HTML, CSS e JavaScript para ajudar motoristas a decidirem de forma rápida e prática se compensa mais abastecer com **Etanol** ou **Gasolina**.

---

## 📱 Sobre o Projeto

Este projeto foi criado como o primeiro desafio prático de desenvolvimento web para consolidação de conhecimentos em front-end. A ferramenta calcula a relação de preço entre os dois combustíveis com base na tradicional regra dos 70% e apresenta o resultado visualmente de forma dinâmica.

---

## 🚀 Funcionalidades

* **Cálculo Dinâmico:** Compara o preço do etanol em relação à gasolina instantaneamente.
* **Interface Responsiva:** Desenvolvido com foco mobile-first, adaptando-se perfeitamente a telemóveis, tablets e computadores.
* **Feedback Visual:** Altera o design e o texto do resultado com base na melhor opção para o utilizador.
* **Caixa de Informação:** Inclui uma breve explicação técnica sobre o motivo da regra dos 70%.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica da página.
* **CSS3:** Estilização moderna, variáveis CSS, layout flexível e responsividade.
* **JavaScript:** Lógica de programação, manipulação do DOM e eventos de clique.
